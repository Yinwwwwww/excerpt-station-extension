# 摘录中转站

用两次点击代替长距离拖选：确定首尾字符，把需要的内容先暂存，再按顺序一次复制。

「摘录中转站」是一个面向当前摘录任务的轻量工作区。它不保存完整剪贴板历史，也不要求你立刻切换到笔记或文档应用：连续收集多个片段、调整顺序，再把结果一次性粘贴到真正需要的位置。

## 核心能力

- **两次点击定位**：点击一个端点字符，正常滚动，再点击另一个端点字符；支持从后向前选取，并包含两端字符。
- **多个片段共存**：片段不会被下一次摘录覆盖，可勾选、全选、删除和撤销删除。
- **按意图编排**：通过六点拖拽调整顺序，“复制所选”始终按面板从上到下组合。
- **自动复制**：每次生成新片段后自动复制该片段；需要时再组合复制多段内容。
- **轻量、临时、本地**：内容只保留在当前页面或当前应用运行会话中，不上传云端。

## macOS 版

### 安装

1. 下载并解压 [macOS 安装包](downloads/摘录中转站-macOS-MVP-v0.1.17-arm64.zip)。
2. 将 `摘录中转站.app` 移到“应用程序”文件夹。
3. 首次打开时，右键应用并选择“打开”。如果系统仍阻止启动，请前往“系统设置 → 隐私与安全性”，确认文件来自本仓库后选择“仍要打开”。
4. 按提示在“系统设置 → 隐私与安全性 → 辅助功能”中允许“摘录中转站”。授权绑定当前应用副本；移动、替换或升级应用后，可能需要移除旧条目并重新授权。

### 使用

1. 点击悬浮“+”或面板中的“新建片段”。
2. 将定位标记移到第一个端点字符并点击。
3. 正常滚动或切换到另一位置，再点击第二个端点字符。
4. 片段生成并自动复制；继续摘录，或展开中转站进行勾选、删除和拖拽排序。
5. 点击“复制所选”，按当前顺序一次复制全部已选片段。

目标界面无法直接取词时，可在面板输入框中输入或粘贴内容：按 `Enter` 创建片段，按 `Shift + Enter` 换行。你也可以用它在摘录之间补充标题、说明或过渡句。

### 兼容性说明

- 通常支持 TextEdit、Pages 等公开标准文字结构的 macOS 控件。
- 已针对 Chrome、Safari、Codex、常见 Chromium / Electron 网页文字结构以及飞书 macOS 应用进行适配；实际效果仍取决于应用版本和它公开的辅助功能结构。
- PDF 阅读器、Office、复杂网页编辑器和虚拟列表可能只能获取部分范围、纯文本，或无法跨文字容器摘录。
- Canvas、视频画面、游戏、远程桌面、扫描图片及其他未公开文字结构的自绘界面无法直接取词，可使用输入框兜底。
- 出于安全原因，不读取密码框或受保护的安全输入内容。

## 浏览器扩展版

### 安装

#### Chrome

1. 下载并解压 [浏览器扩展](downloads/excerpt-station-extension-mvp-v0.7.2.zip)。
2. 打开 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压得到的整个 `excerpt-station-extension` 文件夹。
5. 建议将“摘录中转站”固定到浏览器工具栏。

#### Microsoft Edge

1. 打开 `edge://extensions` 并开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择解压得到的整个 `excerpt-station-extension` 文件夹。

如需在本地 HTML 文件中使用，请在扩展详情页开启“允许访问文件网址”。

### 使用

1. 在普通网页中点击浏览器工具栏上的扩展图标。
2. 点击“新建片段”，再依次点击范围的两个端点字符；起点确定后可自由滚动。
3. 在悬浮中转站中勾选、全选、删除、撤销或拖拽排序。
4. 点击“复制所选”，片段会按当前顺序组合，并在片段之间加入一个空段落。

扩展支持标题、段落、粗体、链接、列表、表格、代码块和标准图片，可同时写入 `text/html` 与 `text/plain`。目标应用不支持富文本时会使用纯文本。

### 当前限制

- 只处理当前标签页的标准网页 DOM；刷新、关闭中转站或跨页面导航后，当前片段会清空。
- 不支持浏览器内置 PDF、Canvas、视频、输入框、关闭的 Shadow DOM，以及跨域 iframe 间的连续选取。
- 浏览器内部页面、扩展商店等受保护页面不允许注入扩展。
- 虚拟列表滚动后如果卸载了起点节点，需要重新选取。
- 外部 CSS、伪元素和字体不会完整嵌入，因此不保证粘贴后的像素级一致。
- 图片保留为绝对 `http/https` 地址；受登录、防盗链或目标应用策略影响时，粘贴后可能无法显示。
- 单页最多暂存 50 个片段，合计约 8 MB。

## 隐私与权限

所有摘录内容均在本地处理，不包含云同步或内容上传。

浏览器扩展使用以下最小必要权限：

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户点击扩展后，临时访问当前标签页 |
| `scripting` | 按需注入选取功能和悬浮中转站 |
| `clipboardWrite` | 写入用户主动选取或组合的内容 |
| `offscreen` | 在 Manifest V3 后台稳定写入富文本剪贴板 |
| `storage` | 仅在浏览器本地保存颜色和悬浮按钮形态偏好 |

扩展不读取剪贴板、不发送分析请求，也不把摘录内容写入浏览器长期存储。macOS 应用的诊断日志不记录摘录正文，只记录失败类型、界面角色、进程和耗时等排障信息。
